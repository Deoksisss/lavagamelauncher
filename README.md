# GameTracker 🎮

Современное десктопное приложение для всестороннего отслеживания игровой активности на ПК и консолях.

## Быстрый запуск
1. **Через ярлык на рабочем столе**:
   Нажмите на ярлык **GameTracker** на рабочем столе. Приложение автоматически запустит локальный сервер и откроется в виде нативного отдельного окна (app mode) без рамок и адресной строки браузера.

2. **Вручную через скрипт**:
   Запустите файл `Launch.bat` в папке проекта:
   `C:\Users\Deoksisss\.gemini\antigravity\scratch\GameTracker\Launch.bat`

## Возможности
- **Умный поиск игр с автокомплитом**: при вводе названия (например, «star») предлагаются варианты (Starcraft, Starfield, Star Wars Jedi и др.) с автоматическим получением вертикальных обложек высокой четкости.
- **Поддержка несуществующих / кастомных игр**: возможность создать игру под любым названием без обложки.
- **Вертикальные обложки в стиле Steam**: стандартное соотношение 2:3 со скругленными углами.
- **Загрузка и кадрирование обложек с ПК**: загружаемое изображение автоматически проверяется на соотношение 2:3; если пропорции не совпадают, изображение аккуратно обрезается по центру и масштабируется до 600×900.
- **Статусы прохождения**: «Играю», «Планирую играть», «Прошел», «Отложил», «Забросил».
- **Автоматический трекинг времени по .exe**: при указании пути к исполняемому файлу сервис в фоне проверяет запущенные процессы и считает часы игры.
- **Ручной ввод базового времени**: можно указать начальное количество часов (например, 50 ч), и все новые часы отслеживаются от этого значения.
- **Заметки и ToDo-лист задач**: в меню игры можно вести записи и отмечать пункты задач (чекбоксы с зачеркиванием).
- **Интеграция со Steam**: автоматический поиск установленных игр через `libraryfolders.vdf` и `appmanifest_*.acf`, автоопределение исполняемых файлов, метка Steam и фильтр. Обновление только при запуске/перезапуске или нажатии кнопки «Обновить Steam».
- **Платформы**: PC, PlayStation, Switch, Xbox, Steam Deck (выделен как отдельная консоль).
- **Меню статистики**:
  - Топ игр за день, неделю, месяц, год.
  - Количество активных игр и общее время.
  - Интерактивная круговая диаграмма (Pie Chart) распределения времени.
  - Горизонтальный график (Horizontal Bar Chart) активности по часам/дням/неделям с возможностью изменения интервалов.
- **График активности в карточке каждой игры**: персональный горизонтальный график времени для выбранной игры.
